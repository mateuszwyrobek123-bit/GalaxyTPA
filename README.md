# GalaxyTPA

Plugin TPA z GUI dla Paper/Spigot 1.21.x (Java 21), bez permisji.

- Najazd na wiadomość gracza na czacie -> statystyki, klik -> GUI
- Komendy: `/tpa`, `/tpaccept`, `/tpdeny`, `/galaxytpa reload` (tylko OP)
- Cały wygląd GUI, wiadomości i ustawienia w `plugins/GalaxyTPA/config.yml`

## Budowanie
`mvn package` -> `target/GalaxyTPA-1.0.0.jar`. Na GitHubie jar buduje się sam w Actions.
